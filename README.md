### 🚀 Projeto atual — Uay Estoque

Atualmente estou desenvolvendo o **Uay Estoque**, uma solução voltada para o controle de estoque e gerenciamento das operações técnicas da empresa.

O projeto conta com:

* 📦 Controle de estoque e materiais
* 🔢 Gerenciamento de equipamentos e números de série
* 🛠️ Alocação de equipamentos para técnicos
* 📋 Controle de ordens de serviço
* 📱 Aplicação mobile para técnicos em campo
* 🌐 Sistema web para gestão
* 🔌 API para integração entre aplicações
* 📊 Acompanhamento das movimentações e operações

O objetivo é transformar processos que antes dependiam de controles manuais em uma **plataforma integrada para gestão de estoque e operações de campo**.
